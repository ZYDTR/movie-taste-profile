## 先了解我

我的观影诉求：

> I'm not a man that pursuing exciting stuff, more like I need to be moved, I need to be touched, and I need to think deeply.

- **需要有情感深度的好故事。** 好故事可能是第一优先级，但不能只有情节推进；情感是故事成立的一部分。
- **《跳出我天地》是重要参照。** 特别喜欢它真挚、朴实又强烈的情绪；不据此把舞蹈、励志、催泪当作自动加分标签。
- **《香水》特别偏爱，《朗读者》也非常好。** 豆瓣的五星上限掩盖了喜爱程度的差异。
- **从作品水准上最喜欢的剧集是《Ted Lasso》和《火线》。** 我尤其欣赏 Ted Lasso 能把积极的事情表现得有厚度、不鸡汤；它是完成度参照，相似作品可能达不到这个水准。
- **《Prison Break》也可列入最爱。** 作为我的第一部 TV series，长期感情可能有额外加成。
- **对心理题材有兴趣，已经看过很多。** 补充提到《扪心问诊》，推荐时应先核对已看情况。

以上来自我的直接表达；文档中的进一步归纳与推荐是助手的工作假设，保留了依据和未知项。

## 如何用这份资料推荐

先读画像和反馈，再结合个人评分与短评判断。高优先级依据是我的直接反馈，其次是短评中的明确理由；题材、导演或风格相似只能作为辅助。推荐者需要真正了解影片的具体内容，深入思考、广泛检索，说明人物与关系如何发展、情绪如何成立；“复杂”“可分析”本身不够。

排除已看时，请同时读取 `data/known_watched.json` 和 `data/personal_preferences.json` 中的 `series_preferences`。未出现在记录中，不等于我现实中没看过；剧名层面的口述也不代表逐季全部看过。

原豆瓣快照为 **107 条**，其中 **104 条有星级、43 条有短评**；口述补充与网页评分分开保存。数值评分未知就保留未知，个人偏爱强度也不换算成虚构星级。四部想看尚无我的观影后反馈；《莫扎特传》已看但评价未知。

## 数据复现

仅使用 Python 标准库，在仓库根目录执行：

```sh
python3 scripts/build_library.py
python3 scripts/build_complete_profile.py
```

第一条离线校验并重建评分表及 JSON，第二条生成完整阅读文件。它们不会自动连接豆瓣，也不会更新网页快照。
